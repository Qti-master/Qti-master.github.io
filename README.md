# GitHub Pages 개발자 포트폴리오

정적 HTML/CSS/JavaScript만 사용하는 원페이지 개발자 포트폴리오입니다. GitHub Pages의 `main` 브랜치 `/root` 배포에 맞춰 루트에 `index.html`을 두었습니다.

## 파일 구조

- `index.html`: 포트폴리오 콘텐츠와 섹션 구조
- `styles.css`: 반응형 레이아웃과 시각 디자인
- `script.js`: 모바일 메뉴, 현재 연도, 섹션 활성화 처리
- `assets/portfolio-workspace.png`: 히어로 섹션용 로컬 이미지
- `.nojekyll`: GitHub Pages에서 Jekyll 처리를 건너뛰기 위한 파일

## 수정할 샘플 정보

- `홍길동`: 실제 이름 또는 닉네임
- `hello@example.com`: 실제 이메일 주소
- `https://github.com/your-github-id`: 실제 GitHub 프로필
- 프로젝트 카드의 제목, 설명, 기술 태그, 저장소 링크
- 경력 타임라인의 회사명, 기간, 역할

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 push합니다.
2. GitHub 저장소의 `Settings`로 이동합니다.
3. `Pages` 메뉴에서 `Build and deployment`를 찾습니다.
4. `Source`를 `Deploy from a branch`로 설정합니다.
5. `Branch`는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
6. 배포가 끝난 뒤 표시되는 GitHub Pages URL로 접속해 확인합니다.

로컬에서는 `index.html`을 브라우저로 직접 열어 확인할 수 있습니다.
